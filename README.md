# AccountaBuddy Website

A concept website for **AccountaBuddy**, an app that matches people with an accountability partner to help them reach fitness, work and personal goals. Built as a class project.

## What's on the site

- **Hero:** explains the service, with App Store and Google Play buttons
- **Features and How it works:** what the app does and the 4 steps to get started
- **Interactive demo:** a clickable phone mockup (set a goal, get matched, check in, message your buddy)
- **Web dashboard:** a working goal tracker that saves progress in your browser
- **Success stories:** user testimonials
- **Blog:** goal-setting tips and success stories that open on the page
- **Sign-up form and social sharing:** share buttons for X, Facebook and LinkedIn

The sign-up form is a demo. It shows a confirmation but doesn't send data anywhere.

## Files

| File | What it does |
|------|--------------|
| `index.html` | The page content and structure |
| `style.css` | Colors, fonts, layout, mobile and dark mode styles |
| `script.js` | The interactive demo, dashboard, blog reader, sign-up and share buttons |

## Run it locally

Download the files and open `index.html` in any browser. No install needed.

## Put it online with GitHub Pages

1. In this repository, go to **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose the **main** branch and the **/ (root)** folder, then click **Save**.
4. After a minute or two, the site will be live at `https://<your-username>.github.io/<repo-name>/`.
